[x] 0.4 요청 넷 조사 — 구조 출제·자동완성·LLM·왕초보를 병렬 세션 넷으로

## 동기

앱을 쓴 사용자가 요청 넷을 냈다. ① 문제가 너무 언어 중심적이고 보여주는 코드가 일부분뿐이다 ② 클론 코딩에 IDE 급 자동완성(괄호 포함)을 넣고 싶다 ③ 리포 이해·출제에 AI 를 쓰는 것을 어떻게 보는가 ④ 그 언어를 전혀 모르는 사람을 위한 왕초보 세션. 사용자가 병렬 세션을 지정했다.

## 방법

Opus 세션 넷을 축별로 띄웠다(구조 출제 / 자동완성 / LLM / 왕초보). 각 세션에 정본·결정 등록부·제약(Rust ≤2,800 · LLM 없이 동작 · ko 정본)을 주고, 리포 수정 금지·근거는 `파일:줄` 인용으로 묶었다. 보고서 넷은 세션 스크래치패드에 있다(`A-structure-cards.md` 324줄 · `B-autocomplete.md` 456 · `C-llm.md` 516 · `D-beginner.md` 410).

## 공통 결론

**네 요청 중 셋은 설계 논쟁이 아니라 미구현·고장이었다.** 요청의 언어는 「이렇게 바꾸자」인데 원인은 「약속한 것이 아직 없다」였다.

## 판단

### 자동완성 — 있던 규칙의 확장

원칙 한 줄로 정리됐다: **고르지 않은 텍스트를 만드는 보조는 페이딩, 이미 고른 텍스트의 타건만 줄이는 보조는 페이딩 안 함.** 현행 `autoIndent`(1·2 brackets / 3 none)가 그 규칙의 첫 사례라 새 원칙이 아니다.

실측이 칸을 정했다 — 닫힘만 있는 줄이 TS 비공백 줄의 12.5%(Rust 15.9 · Python 4.0)라 3단계에서만 공짜 점수가 된다. 단어 기반 제안은 식별자 타건의 43.7%를 줄이면서 최종 텍스트를 안 바꿔 `pct` 가 구조적으로 불변. 둘 다 번들 +0 바이트.

L3(언어 서비스)는 폐기 권고 — `ts.worker` 1.29 MB gzip 이 Monaco 청크 예산 1.2 MB 를 워커 하나로 초과하고, 떼어낸 12~40줄 블록엔 tsconfig 가 없어 무동작이며, TS 만 똑똑해지는 불균형은 정본 §2 위에서 못 고친다.

오염 대책은 `peeks` 선례를 그대로 — `AssistCount{keyed, assisted, pasted, accepted}` 를 감점 없이 기록만.

### LLM — 붙여도 이 문제는 안 고쳐진다

결정론적 검증기가 **완전히** 통과시킬 수 있는 카드는 빈칸형(정답 = 원문 토큰 byte 일치)과 지목형(정답 = `.scm` 캡처 자리)뿐인데, 그 둘은 사전만 채우면 LLM 없이 나온다. 반대로 검증 못 하는 것(의미형의 값 주장 · 「그것이 참이 되는 조건」 진단문)이 지금 99.5% 다. LLM 을 카드에 붙이면 결정론이 이미 잘하는 곳에서만 통과한다.

현황은 S0 이 아니라 **S0 마이너스** — D106 대로 전송 자체가 없고, CSP `connect-src 'self' ipc:`(`docs/06:225`)라 WebView 가 외부 호스트에 물리적으로 못 닿는다. 다만 D129 일지가 `llm_ask`+reqwest ~70줄과 로컬 모델 provider ~40줄을 이미 예약해 뒀고(예산 실측 2,331/2,800), 그 예산 상향이 **로컬 모델(Gemma)을 4단에 넣는 대화에서 시작됐다**는 맥락도 남아 있다.

권고: **S0 유지 + LLM 은 사전 저작 시점(기여자 책상)으로.** 산출물이 리포에 커밋되는 YAML 이라 키 없는 사용자에게도 똑같이 도착한다. 남는 결손은 §2.3 의 원리적인 것들(「이 추상화가 적절한가」·모듈 책임을 사람 말로)이고, 그건 S2/S3 이며 정본 §5 를 고치는 일이다.

### 왕초보 — 정본을 다시 열 필요 없음

사용자가 쓴 말은 「**해당 언어의** 왕초보」이지 「프로그래밍이 처음」이 아니다 — 방안 E ①번 상황 그대로다. 정본이 거부한 것은 「별도 입문 **과정**·배치고사」이고 E-2 는 「0장」을 채택 상태로 남겼다. E-1·E-3·E-5 는 이미 동작한다(`unknown-rank.ts:33` → `new-rank.ts:79` → `data/session.ts:190`, `universal` 26쌍, `newcomerFlag` → `session-flow.ts:699`).
