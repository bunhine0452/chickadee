## 16px 판정

캔버스 래스터를 열 단위로 훑어 먹 → 종이 → 먹(캡–뺨–턱받이) 3단이 나오는 열 수와 흰 띠 높이를 센다 (합격 = 열 2 이상 + 띠 2px 이상). `verify.json` 이 원본.

| 파일 | 16px | 24px | 32px |
|---|---|---|---|
| 배지 · 정사각 · 원본 | ✗ (1열) | – | ✓ 24열 · 뺨 18px |
| **파비콘(머리 크롭)** | **✓ 4열 · 뺨 3px** | ✓ 8열 | ✓ 14열 |

→ 32px 이상은 배지/정사각, 그 아래는 파비콘 크롭. 앱 안에서는 `ink-home.html` 마스트헤드(66px)와 `ink-session.html` 작업 띠(46px)에 배지를 쓴다. 파비콘은 두 페이지 모두 정적 data URI.

## 마스코트 = 같은 그림

마스코트 Dee 는 이 SVG 를 **복사해 색만 판(plate) 변수로 바꾼 것**이다(`design/src/ink/mascot.svg.html`, 홈·세션에 박혀 있음). 경로 한 벌(`#deePlates`)을 심볼 셋이 공유한다 — `#dee` 배지(스티커·레일·범례·요약) · `#deeBird` 새+가지 크림 다이컷(길잡이·횃대) · `#deeHead` 머리(16~20px) · `#logo` 고정색 브랜드 마크. 잉크 겹에 따라 판이 켜진다: 0 빈 판 · 1 회색 스크린 · 2 먹판(먹·회색) · 3 +청판 · 4 +진홍·황판. 배지는 24px 부터 3단 판정 통과(24px 14열 · 32px 24열), 16px 는 머리 크롭.
