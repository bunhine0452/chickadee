# Chickadee 디자인 — 현재 유효한 것만

> 제품 결정과 서비스 문서는 **`.oculpm/discussion/vibe-code-study-app/discussion.md`** 의 「결론」이 정본이다. 이 README 는 파일 안내다.
> 방향: **「잉크」(리소그래프) + 박새** — 사용자 결정. 로고 **`logo/chickadee-logo.svg`** 확정(변경 금지), 마스코트는 그 SVG 를 복사해 색만 판(plate) 변수로 바꾼 것.

전부 자립형 HTML(외부 의존성은 폰트 CDN 뿐)이라 더블클릭으로 열린다. `index.html` 이 목차.

## 지켜야 할 것 (요약 — 정본은 discussion.md §3·§6)

- 본문은 조용하게, 나머지는 잉크답게. 읽어야 하는 텍스트 위에 잉크를 얹지 않는다. 13px 미만 토큰 없음. 본문 한 줄 한글 35~45자(`--measure:36em`). 대비 7:1.
- 「모르겠어요」는 벌이 아니다. 하트·목숨·리그 금지. 맞혀도 노출. 누르면 이득이 보여야 한다.
- 피드백 슬롯 예약(0px 점프) · 세션은 전체화면, Esc 즉시 이탈, 확인 모달 없음 · 진행바는 시간 비례.
- 로고 그림은 바꾸지 않는다. 마스코트도 같은 그림이다 — 색(판)만 잉크 겹에 따라 켜진다.
- AI 클리셰 금지(보라·인디고 그라디언트, 유리질감, 그라디언트 텍스트).

## 검수 방법

- 세션: Playwright 로 5판 전 흐름 자동 주행(정답·오답·사다리·점프·복귀·LIFER·필사 채점·이의·왜·구조 채점·요약·야간반). 콘솔·페이지 오류 0, `?dev=1` 에서 13px 미만 0 · 본문 최대 40자.
- 로고·마스코트: 캔버스 래스터를 열 단위로 훑어 캡–뺨–턱받이 3단이 살아 있는지 센다(`logo/verify.json`, 홈 `__audit.dee`).

## 남은 것

- 홈을 `src/ink/` 빌드로 이전(지금은 세션이 홈에서 추출).
- WebKit(Tauri) 렌더 성능 실측.
- 세션 데이터는 목업용 하드코딩 — 실제로는 tree-sitter 추출 + 문법 사전 + 커밋 정답지가 채운다.
