## 밟으면 터지는 자리 (M5 에서 실제로 밟았다)

- **Rust 줄 예산이 정확히 찼다 — 2,300/2,300, 여유 0.** M6 의 `repo_glob_read`(~30)도,
  `CHICKADEE_DEBUG` 환경변수도 **들어가지 않는다**. D68 을 다시 여는 것이 착수 전 사용자
  결정이다. 처음 쓴 대로면 2,314 였고 `data_dir` 을 세 파일이 나눠 쓰게 하고(같은 네 줄이
  세 벌 있었다) 오류 갈래를 `match` 로 접어 겨우 맞췄다. **한 줄이라도 더하기 전에
  `bash scripts/check-rust-budget.sh` 를 돌려라.**
- **`import.meta` 가 Playwright 안에서 안 돈다.** Playwright 는 TS 를 **CJS 로** 옮겨 돌린다.
  `createRequire(import.meta.url)` 도 못 쓰고, 더 크게는 **`packages/dictionary` 의 번들이
  Vite 의 `import.meta.glob`** 이라 사전·파생 층을 Playwright 프로세스에서 열 수 없다.
  그래서 시드는 vitest 가 굽고 Playwright 는 결과만 연다 — 그 경계를 지우려 들지 마라.
  상수는 `build-seed-const.ts` 가 갖는다(둘 다 열 수 있는 유일한 파일이다).
- **`vite preview` 는 `--host 127.0.0.1` 이 있어야 한다.** 기본값 `localhost` 는 ::1 로만
  열려 `baseURL` 의 127.0.0.1 이 붙지 못한다 — 오류 대신 `webServer` 가 120초를 기다리다 죽어
  「Playwright 가 고장 났다」처럼 보인다.
- **WKWebView 는 `<button>.focus()` 를 조용히 무시한다.** macOS 의 「모든 항목에 Tab 이동」이
  꺼져 있으면 그렇다. 포커스를 옮기는 코드는 **옮겨졌는지 확인하고 `tabindex="-1"` 문맥으로
  물러서야** 한다 — `components/session/focus.ts` 가 그 자리다. 같은 이유로 webkit 에서는
  `Tab` 이 단추에 닿지 않는다(`Option+Tab` 이라야 한다) — 앱 버그가 아니라 엔진 기본값이다.
- **`AnimationPlayState` 에 `'pending'` 이 없다**(lib.dom 에 없을 뿐 엔진에는 있다).
  타입만 보고 빼면 갓 시작한 애니메이션을 「끝났다」로 읽어 **전환 도중의 색을 잰다** —
  야간반 전환 중 1.91:1, 교정지 등장 중 3.04:1 같은 거짓 실패가 난다.
- **게이트는 재기 전에 애니메이션이 멎기를 기다려야 한다**(`settled()`).
- **GitHub 이슈 폼은 `body=` 를 무시한다.** 필드 id 로만 미리 채워진다. `issueUrl` 이
  존재하지 않는 템플릿 이름에 모든 것을 `body` 하나로 담고 있었고, 링크는 **열리는데 빈
  칸으로** 열렸다. 오류가 안 나서 눈치채기 어렵다.
- **`exactOptionalPropertyTypes` 는 `{ commit: undefined }` 를 「키 없음」으로 안 본다.**
  **`vitest` 는 통과하는데 `tsc` 만 잡는다** — 로컬 테스트가 초록이어도
  `npx tsc --noEmit -p apps/desktop/tsconfig.json` 을 따로 돌려라. M4 의 CI 빨간불이 이것이었다.
- **`keyring` 의 `crypto-openssl` 을 고르지 마라** — `openssl-src` 를 끌고 와 CI 마다 OpenSSL 을

- **`PanicHookInfo` 는 Rust 1.81 부터다** — 워크스페이스 MSRV 를 1.81 로 올렸다(D109).
- **프라이버시 문구는 코드보다 앞서면 안 된다.** 06 §3.6 이 「키를 넣고 보내기를 누르면

  (0.1.0 / 전송이 열린 뒤)이고, 전송을 켜는 판이 뒷문구로 갈아 끼워야 한다.
- (앞에서 이어지는 것) **`shell` 의 grep 이 UTF-8 로케일이 아니면 한국어가 든 파일을
  바이너리로 본다** — `export LC_ALL=en_US.UTF-8` 를 먼저 세워라. `docs/00-overview.md` 의
