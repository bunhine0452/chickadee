## M0 이 남긴 것 — 시작 전에 알아야 할 것
- **Rust 예산이 558/1500 줄 찼다.** M1 이 `git`·`parse` 크레이트와 잡 러너를 얹으므로 여기가
  가장 빡빡한 제약이다. `crates/git ≤ 400` · `crates/parse ≤ 450`(01 §4). 도메인 어휘를
  주석에까지 쓰지 말 것 — `scripts/check-rust-budget.sh` 의 grep 이 주석도 본다.
- **`git2` 는 `>= 0.21.0` 으로 고정한다.** 그 아래는 open unsound 권고 3건(RUSTSEC-2026-0008 ·
  -0183 · -0184)이고, `crates/git` 이 신뢰할 수 없는 리포를 파싱하므로(06 §4.1) `deny.toml` 에
  무시로 넣지 않았다. 낮은 버전을 쓰면 CI `audit` 잡이 빨개진다.
- **`crates/git`·`crates/parse` 디렉터리는 없다.** 워크스페이스 글롭이 `crates/*` 라 빈 디렉터리는
  cargo 를 통째로 깨뜨린다 — 만들 때 `Cargo.toml` 을 같이 만들고, 루트 `Cargo.toml` 의
  `[workspace.dependencies]` 에 주석 처리해 둔 `chickadee-git`·`chickadee-parse` 두 줄을 켠다.
- **statement 는 열 별칭을 붙이지 않는다(D57).** 새 SELECT 는 열 이름을 그대로 돌려줘야
  `packages/store-sql/src/rows.ts` 의 `fromRow` 가 읽는다. statement 는
  `packages/store-sql/statements/*.sql` 에 `-- @name/@params/@row` 로 추가하고
  `pnpm catalog:build` 로 `StatementMap` 을 다시 생성한다.
- **`packages/text` 가 있다(D50).** `tokenize`·`seedOf`·`mulberry32`·`shuffle` 을 다시 만들지 말고
  `@chickadee/text` 에서 가져다 쓴다 — `concepts` 의 `shape` 파생이 이 토크나이저를 쓴다.
- `packages/concepts`·`packages/dictionary`·`packages/cards` 는 아직 **없다**. M1 에서 만든다
  (01 §4 레이아웃 그대로, `packages/<name>/{package.json,tsconfig.json,src/}`).
- `dictionary/` 는 README 와 `schema/` 빈 폴더만 있다. 내용이 M1 의 몫이다.
- 픽스처는 `bash scripts/make-fixture-repo.sh <tiny|two-commits|projectox-like>` 로 만든다.
  생성물은 `.gitignore` 가 막고 `.steps` 만 커밋된다. `large-100k`·`poly` 는 M1 에서 추가한다.

## 규칙
- 정본 > 설계 문서 > 내 판단. 문서와 어긋나는 것을 발견하면 코드를 문서에 맞추고, 문서를
  바꿔야 하면 `docs/00-overview.md` §4.2.1 에 **D63…** 행을 먼저 추가한 뒤 해당 문서를 고친다.
  체크리스트 항목 제목은 바꾸지 않는다(플랜이 제목으로 참조).
- 얇은 Rust: `crates/**` + `src-tauri/**` 합계 ≤ 1500줄, 도메인 어휘 금지, SQL 리터럴 금지.
  `bash scripts/check-rust-budget.sh` 를 자주 돌린다.
- Rust 는 YAML 을 읽지 않는다(D40). `dict_read{lang}` 이 원문을 넘기고 파싱·검증은 TS 가 한다.
- **리포에 절대 쓰지 않는다.** Tauri `fs` 스코프는 `app_data_dir` 로만 열려 있고 리포 읽기는
  전부 명령 경유다. 인제스트 전후 트리 해시가 같은지 테스트로 고정한다.
- 로그 금지 필드(01 §6): 파일 내용·코드 조각·캡처 excerpt·사용자 답안·절대 경로. Rust 는
  `#[instrument(skip(text, bytes))]`.
- 디자인 결정은 사용자 것이다. 로고와 목업 시각은 바꾸지 않는다. 홈은 `design/ink-home.html`
  과 `design/src/ink/data.js` 가 데이터 모양의 정본이다.
- 병렬 하위 세션이 필요하면 `model: "opus"` 로 띄우고 각자 필요한 절만 읽게 한다. 기계적인
  작업(사전 YAML·골든 픽스처·컴포넌트)은 하위 세션, 경계 판단(Rust↔TS·캡처 규약·스키마)은 직접.
- 작업 단위마다 `journal_write` 로 일지를 쓰고 `plan_update(plan_id="chickadee-build",
  item_id=…)` 로 글리프를 갱신한다(AGENTS.md 규칙).
- 검증 없이 완료라고 말하지 않는다. 실패한 테스트·미측정 항목은 그대로 보고한다.
- **표면 언어(D61 · 루트 `CLAUDE.md`).** 커밋 메시지 · PR · `.github/**` · `README` 류 ·
  **코드 주석·식별자는 영어**. 앱 UI 문구 · 오류 문구 · 사전 YAML 은 **한국어**(조판 규칙이
  한국어 전제다). `docs/**` 설계 6편과 `.oculpm/**` 일지·플랜도 한국어.
- 커밋은 `<type>: <description>` 형식(영어).
- **AI 말투 금지(D62).** README·커밋 메시지·PR·릴리스 노트 등 사람이 읽는 글에 `seamless`·
  `robust`·`powerful`·`leverage`·`혁신적인` 류 낱말, `It's not just X — it's Y` 문형, 근거 없는
  최상급, 이모지 제목, 절마다 붙는 요약 문장을 쓰지 않는다. 목록은 루트 `CLAUDE.md`.
  판정 기준: 「이 문장을 지우면 독자가 잃는 정보가 있나?」 — 없으면 지운다.
- **CI 를 빨간 채로 두지 않는다.** 푸시하면 `lint-type-unit`·`audit`·`build-3os`(3-OS
  `tauri build --debug`)가 돈다. M0 종료 시점에 **5잡 전부 초록**이었으니 빨개지면 네가 깬 것이다.
  `gh run watch <id>` 로 끝까지 보고 간다.
