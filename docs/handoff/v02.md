## 사용자가 이미 정한 것 (다시 묻지 마라)

1. **영어는 사전까지 전부.** 앱 문구만이 아니라 `dictionary/**` 57 YAML(개념 이름·한 줄
   설명·템플릿)까지 영문화하고 `concept.name_en` 을 `ALTER ADD COLUMN` 한다.
2. **리포는 서가 화면 신설 + 마스트헤드 스위처 둘 다.** 홈은 그대로 활성 리포 하나를 본다.
3. **클론 코스는 일일 큐(D12 10~25분) 밖 별도 모드.** 예산 규칙을 건드리지 않고 결과만
   `review_log` 로 개념 겹에 반영한다.
4. **착수 순서** — `chickadee-i18n` P1(뼈대) → `chickadee-settings-gaps` →
   `chickadee-repo-shelf` → `chickadee-i18n` P2·P3 → `chickadee-clone-course`.
   이유는 하나다: i18n 뼈대를 먼저 깔아야 뒤 세 플랜이 만드는 새 문구가 처음부터 `t()` 로
   들어가고 번역 대상이 두 번 늘지 않는다.

결정은 **이미 났다.** 남은 것은 등록부 행 문안을 올리고 문서에 반영하는 절차뿐이다 —
D117(로케일 축, D61 을 개정한다) · D119(서가 화면) · D120(큐 밖 코스) · D118(사전 이중
언어). D120 은 정본 §2 트랙 표에 코스 행이 필요하므로 `docs/00` §4.3 절차를 따른다.

## 밟으면 터지는 자리 (이번 계획이 부딪힌 것)

- **Rust 줄 예산 2,300/2,300 — 여유 0.** 실측했다(`bash scripts/check-rust-budget.sh`).
  **네 플랜 모두 Rust 추가 0줄로 설계했다.** 한 줄이라도 더하려면 D68 을 다시 여는 사용자
  결정이 먼저다. 코스가 `repo_glob_read` 같은 새 명령을 부르고 싶어지면 그 자리에서 멈추고
  `file_read_lines` 로 되돌아와라.
- **원장은 열을 풀 수 없다.** `review_log.session_id`·`session_item_id` 가 NOT NULL 이고
  `02` §2.2 가 원장 변경을 `ALTER … ADD COLUMN` 으로만 허용한다. 그래서 「큐 밖 모드」인
  코스도 결과를 남기려면 **실행마다 `session` 행 1개 + 조각마다 `session_item`** 을 만들어야
  한다. `session_item.role` 은 CHECK 목록(`review·new·retry·prereq·manual·gap`)에 갇혀 있으니
  `manual` 을 재사용하고, 코스 소속은 `clone_step.review_log_id` 로 가른다. SQLite 는 CHECK 를
  ALTER 로 못 고친다 — 새 role 값을 추가하려 들면 원장을 다시 만들어야 한다.
- **행 길이 게이트는 한국어 전제다.** `05` §9 의 본문 30~45자(좁은 패널 22)를 영어에 그대로
  걸면 `tests/gates/design.spec.ts` 가 통째로 거짓 실패한다. D112 가 05 §9 를 이 규칙의
  정본으로 지정했으니 거기부터 고치고 `06` §2 를 따라 맞춘다.
- **조판이 한국어를 전제한다** — `word-break: keep-all` · `--measure` 36em · `josa` 헬퍼.
  정본 §6 의 조판 규칙 자체가 그렇다. en 은 세 개를 다 다시 정해야 한다.
- **골든 픽스처가 한국어 문구를 담고 있다.** `packages/cards`·`packages/grading` 의 골든은
  생성 문구를 그대로 박제한 것이라, 문구를 `t()` 로 옮기면서 **하네스가 로케일을 ko 로
  고정**하지 않으면 골든이 전부 깨진다. 깨진 골든을 다시 녹화하지 마라 — 로케일을 고정하고
  diff 0 을 확인하는 것이 맞다.
- **`concept.name_ko` 는 컬럼 이름이다.** 스키마가 언어를 이름에 박아 뒀다. `name_en` 을
  더하는 쪽이 맞고, `name_ko` 를 `name` 으로 바꾸는 개명은 원장 규칙상 못 한다.
- **`packages/dictionary` 의 번들은 Vite `import.meta.glob`** 이라 Playwright 프로세스에서
  열리지 않는다(m6 의 그 항목이 그대로 적용된다). 사전을 영문화해도 이 경계는 그대로다.
- **리포 등록의 유일한 문은 네이티브 폴더 대화상자다.** 그래서 E2·E3 이 못 쓰였고(m6 §③),
  서가의 「리포 추가」도 같은 한계를 물려받는다 — E2E 로 덮지 못하니 단위·게이트로 덮어라.
- **마스트헤드의 죽은 버튼에는 CSS 와 aria 가 이미 있다**(`.repo-switch`,
  `aria-haspopup="listbox"`). 새로 만들지 말고 `disabled` 를 떼고 목록을 붙여라.
- **설정 화면에는 「저장」 버튼이 없다** — 칸을 바꾸면 그 자리에서 `settings` 로 내려간다.
  새 칸도 그 규약을 따라야 한다.

  는 한국어. **D117 이 이 규칙의 「앱 UI 문구」 부분을 개정한다** — 개정 뒤에도 정본은 ko 다.

- 얇은 Rust 상한 2,300(D68) — 지금 정확히 차 있다. 도메인 어휘·SQL 리터럴 금지.

  `check:motion` · `design:check` · `test:gates` · `test:e2e-ui` ·
  `catalog:build`(statement 를 고치면 **반드시**).
- 리포에 절대 쓰지 않는다. 로그·내보내기 금지 필드(01 §6): 파일 내용·코드 조각·캡처
