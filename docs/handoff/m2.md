### 밟으면 터지는 자리
- **`store_batch` 는 한 번에 200 op 다.** `concepts/src/ingest.ts` 의 `inBatches` 가 그것을
  지킨다 — 새 쓰기 경로를 만들 때 그냥 `ipc.store.batch(ops)` 를 부르면 큰 세션에서 터진다.
- **`concept.universal_id` 는 `concept(id)` 를 참조한다.** 보편 개념(`common/`·`arch/`)을
  먼저 넣지 않으면 외래키가 걸린다. `materializeDict` 가 정렬로 해결해 두었다.
- **`toSqliteBindings` 는 배열·객체를 JSON 문자열로 만든다**(Rust `to_sql` 과 같은 규칙).
  `json_each(:ids)` statement 를 쓸 때 이것을 거치지 않으면 드라이버가 바인딩을 거부한다.
- **macOS 의 `/var` → `/private/var`.** `Repo::open` 은 루트를 `canonicalize` 한다. 경로를
  비교하거나 `strip_prefix` 할 때 한쪽만 정규화하면 조용히 0건이 나온다 — 오류가 아니라
  「빈 리포」로 보인다. `std::env::temp_dir()` 를 쓰는 테스트에서만 드러난다.
- **`vitest.config.ts` 의 `include`.** `apps/*/src/**/*.test.tsx` 가 없으면 화면 테스트가
  **조용히 안 돈다**. M1 중반까지 그랬다.
- **`packages/ui` 의 테스트는 `// @vitest-environment jsdom` 주석이 필요하다.** 루트 설정이
  `node` 라서, 없으면 DOMPurify 가 `sanitize is not a function` 으로 죽는다.
- **`import.meta.glob` 은 전역 선언을 쓰면 안 된다.** 앱에는 `vite/client` 타입이 이미 있어
  중복 선언이 되고, 별도 `.d.ts` 는 이 패키지를 원본으로 컴파일하는 패키지에 안 들어간다.
  `bundle.ts` 의 국소 캐스트가 그 답이다.
- **CI 의 `integration` 잡은 GTK 헤더가 필요하다** — pipeline 테스트가 tauri 앱 크레이트에
  살아서 리눅스에서 `gdk-sys` 를 링크한다. 새 잡을 만들 때 같은 함정이 있다.
- **`cargo fmt --all --check` 를 커밋 전에 돌려라.** 테스트 파일이 예산 밖이라 방심하기 쉬운데
  CI 의 `lint-type-unit` 은 워크스페이스 전체를 본다.

## 규칙
- 정본 > 설계 문서 > 내 판단. 문서와 어긋나는 것을 발견하면 코드를 문서에 맞추고, 문서를

  체크리스트 항목 제목은 바꾸지 않는다(플랜이 제목으로 참조).
- 얇은 Rust: 게이트는 잠정 2,100(D68). 도메인 어휘 금지·SQL 리터럴 금지·`println!` 금지.
  `bash scripts/check-rust-budget.sh` 를 자주 돌린다. **M2 는 Rust 를 거의 안 늘려야 한다** —
  세션·채점·큐는 전부 TS 다.
- **리포에 절대 쓰지 않는다.** 인제스트 전후 트리 해시가 같은지 테스트가 고정하고 있다.
- 로그 금지 필드(01 §6): 파일 내용·코드 조각·캡처 excerpt·사용자 답안·절대 경로.
  `@chickadee/ipc-client` 의 `log` 를 써라 — 이름으로 거른다. `console` 은 그 파일 밖에서 금지다.
- 디자인 결정은 사용자 것이다. 로고와 목업 시각은 바꾸지 않는다. 세션은
  `design/ink-session.html` 과 `design/src/ink/{data,t0,t1,t2}.js` 가 정본이다.
- 병렬 하위 세션이 필요하면 `model: "opus"` 로 띄우고 각자 필요한 절만 읽게 한다. **M1 에서
  실제로 효과가 있었던 분배**: 기계적인 작업(사전 YAML·골든 픽스처·컴포넌트·벤치)은 하위 세션,
  경계 판단(Rust↔TS·스키마·상태 모델)은 직접. 하위 세션에는 **검증 명령을 명시하고 그 실제
  출력을 보고하게** 하라 — 그러지 않으면 「했다」만 돌아온다.
  주의: 하위 세션이 같은 `Cargo.toml`·`package.json`·`vitest.config.ts` 를 동시에 고치면
  워크스페이스가 잠깐 깨진다(M1 에서 `[[bench]]` 가 파일보다 먼저 들어와 cargo 가 전부 멈췄다).

- 검증 없이 완료라고 말하지 않는다. 실패한 테스트·미측정 항목은 그대로 보고한다.
