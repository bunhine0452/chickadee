  체크리스트 항목 제목은 바꾸지 않는다.
- 얇은 Rust: 상한 **2,300**(D68). 도메인 어휘 금지·SQL 리터럴 금지·`println!` 금지.
- 게이트 스크립트: `pnpm check:rust` · `pnpm check:contrast` · `pnpm check:motion` ·
  `pnpm design:check` · `pnpm catalog:build`(statement 를 고치면 **반드시**).
- **리포에 절대 쓰지 않는다.** 인제스트 전후 트리 해시가 같은지 테스트가 고정하고 있다.
- 로그 금지 필드(01 §6): 파일 내용·코드 조각·캡처 excerpt·사용자 답안·**절대 경로**.
  M5 는 릴리스라 이 규칙이 가장 위험하다 — 크래시 리포트와 진단 번들이 경로를 실어 나른다.
- 디자인 결정은 사용자 것이다. 로고와 목업 시각은 바꾸지 않는다.
- 병렬 하위 세션은 `model: "opus"` 로, **담당 파일 집합을 못박고 검증 명령의 실제 출력을
  보고하게** 하라. M4 에서 다섯 세션이 서로 다른 디렉터리만 만져 충돌이 0이었다.
  같은 `package.json`·`vitest.config.ts`·`docs/**`·패키지 `index.ts` 를 둘이 고치면 깨진다
  (M4 는 `index.ts` 를 전부 상위 세션이 썼다).
- 작업 단위마다 `journal_write` + `plan_update`.
- 검증 없이 완료라고 말하지 않는다. 실패한 테스트·미측정 항목은 그대로 보고한다.
- **표면 언어(D61).** 커밋·PR·`.github/**`·`README` 류는 영어. 코드 주석은 한국어,
  식별자는 영어. 앱 UI 문구·사전 YAML·`docs/**`·`.oculpm/**` 는 한국어.
- 커밋은 `<type>: <description>`(영어). **AI 말투 금지(D62)**.
- **CI 를 빨간 채로 두지 않는다.** `gh run watch <id>` 로 끝까지 보고 간다.
