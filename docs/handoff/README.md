# 인계 프롬프트

마일스톤 하나에 파일 하나. 다음 세션에 **그대로 붙여 넣는** 프롬프트다.

| 파일 | 마일스톤 | 상태 |
|---|---|---|
| `m1.md` | M1 · 인제스트 수직 절단 | 끝남 |
| `m2.md` | M2 · T0 세션 수직 절단 | 끝남 |
| `m3.md` | M3 · T1 클론 코딩 | 끝남 |
| `m4.md` | M4 · T2 구조 | 끝남 |
| `m5.md` | M5 · 릴리스 준비 | 끝남 |
| `m6.md` | M6 · MVP 이후 | 대기 |
| `v02.md` | 0.2 · 사용자 요청 4건 (언어 선택 · 리포 서가 · 설정 보완 · 클론 코스) | 진행 중 — i18n P0·P1 끝 |

`v02.md` 만 §5 의 마일스톤이 아니다 — 사용자가 직접 요청한 기능 넷이고 M6 와 배타가
아니다. 무엇을 먼저 할지는 사용자가 정한다.

## 왜 파일로 두나

인계는 대화에 남기면 사라진다. 다음 세션은 새 창이고, 앞 세션이 무엇을 이미 정했는지·어디에
지뢰를 남겼는지 모른 채 시작한다. M0 에서 실제로 겪은 것들이 그런 종류다 — 빈 `crates/*`
디렉터리가 cargo 를 통째로 깨뜨리는 것, `git2 < 0.21` 이 CI 를 빨갛게 만드는 것, 이미 있는
패키지를 다시 만들려 드는 것. 문서를 읽어서는 알 수 없고 겪어야만 아는 것들이라 따로 적는다.

## 무엇을 담나

1. **목표와 읽을 순서** — 「이것만」 읽게 좁힌다. 6편을 다 읽히면 아무것도 못 한다.
2. **할 일** — 플랜 항목 id 를 의존 순서로.
3. **끝났다는 증거** — `docs/00-overview.md` §5 의 그 마일스톤 문장 그대로.
4. **앞 마일스톤이 남긴 것** — 예산 잔량, 고정해야 할 버전, 이미 있어서 다시 만들면 안 되는 것,
   밟으면 터지는 자리.
5. **규칙** — 정본 우선, 결정 등록부 선행, 표면 언어(D61), AI 말투 금지(D62), CI 초록 유지.
6. **이미 결정된 것** — 다시 묻지 않도록 결정 번호와 함께.
7. **보고 형식**.

## 갱신

마일스톤이 끝나면 그 세션이 다음 마일스톤 파일을 새로 쓰고 이 표에 줄을 추가한다.
끝난 파일은 지우지 않는다 — 그 시점의 전제가 무엇이었는지가 나중에 답이 된다.
